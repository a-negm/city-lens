# CityLens

CityLens is a map-first product that helps people understand how urban conditions in Berlin may affect health and daily life.

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- MapLibre GL JS

## MVP
- 2D map
- selectable Berlin areas
- one active layer at a time
- side panel with area details
- deterministic scoring
- AI explanations later

## Workflow
- one feature spec at a time
- one branch per feature
- Codex plans first, then implements
